# TilePad
**TilePad** — панель настраиваемых кнопок-плиток для быстрого запуска действий: звуков, сайтов, программ и файлов. Поддерживает гифки, картинки, темы, категории, запись голоса и массовое редактирование.

# Описание приложения

**TilePad** — десктопное приложение (Python + PyQt6) для Windows/Linux/macOS, создающее панель интерактивных кнопок-плиток для быстрого доступа к действиям.

## Основное назначение
Панель с кнопками, каждая из которых запускает пользовательские действия по клику. Окно безрамочное, со скруглёнными углами, перетаскиванием за верхнюю область и изменением размера за края.

## Функции кнопок
- **Звук** — воспроизведение аудиофайла (wav/mp3/ogg/flac).
- **Сайт** — открытие URL в браузере с предварительной проверкой доступности (HEAD-запрос, фолбэк на GET).
- **Запуск** — запуск программы/команды (exe, bat, lnk, `steam://`, `ms-settings:` и т.п.).
- **Файл** — открытие файла/папки средствами ОС.
- **Несколько действий** на одной кнопке — выполняются по порядку; на плитке показывается счётчик.

## Возможности кастомизации
- **Текст**: переименование (до 20 символов), выбор шрифта (семейство, размер 6–28 pt, жирность).
- **Цвета кнопки**: фон и текст через палитру пресетов, HEX-ввод или системный color picker.
- **Изображения и гифки**: установка из файла (png/jpg/bmp/webp/gif/apng), поиск GIF в интернете через **Tenor API** (по ключу), вставка прямой ссылки.
- **Фон окна**: цвет + картинка/гифка.
- **Тема**: цвета окна (фон, панель, акцент, текст) и кнопок.
- **Логотип приложения**: смена на картинку/GIF (файл или Tenor), сброс на стандартный.
- **Размер плиток**: адаптивный (64–104 px в зависимости от ширины окна).

## Организация
- **Категории**: создание, переименование, удаление; переключение через меню; хлебные крошки.
- **Перетаскивание** плиток для смены порядка (с анимацией).
- **Дублирование** кнопки (Ctrl+D или контекстное меню).
- **Режим множественного выбора**: выбор всех/половины/отдельных, массовое изменение цвета, шрифта, картинки/гифки, удаление.
- **Закрепление поверх окон** (pin).

## Запись голоса
Встроенный рекордер (до 10 сек): запись с микрофона, отображение волновой формы, выбор начала/конца (обрезка), прослушивание и сохранение в WAV.

## Прочее
- **Автосохранение** состояния в `~/.animated_buttons_app/state.json` (тема, кнопки, категории, логотип, ключ Tenor, pin).
- Медиафайлы (скачанные гифки, записи голоса) хранятся в `~/.animated_buttons_app/media`.
- Кастомные диалоги в едином тёмном стиле (сообщения, подтверждения, ввод текста, выбор цвета, шрифта, действий).
- Анимации: появление плиток (fade), нажатие, подъём при перетаскивании, hover-эффекты.
- GIF-анимации на кнопках/логотипе/фоне останавливаются, когда окно неактивно (экономия ресурсов).
- Контекстное меню плитки (ПКМ) — все настройки; ЛКМ — запуск действий.
